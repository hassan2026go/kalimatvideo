# Nabdh Messenger (starter)

This is a starter Android project scaffold for the Nabdh Messenger app.

## Before building
1. Extract this ZIP on your phone.
2. In your private GitHub repository, upload the **contents** of this folder (not the ZIP itself), keeping the directory structure.
3. In Firebase Console, register an Android app with package name `com.nabdh.messenger`.
4. Download `google-services.json` and place it in `app/google-services.json` locally. Do not paste its contents into chat or commit it to a public repository.
5. Configure Firebase Authentication (Email/Password) and Cloud Firestore.
6. Add restrictive Firestore security rules before testing with real accounts.

The first build is only a technical starter. It is not a finished or production-secure messenger yet.
